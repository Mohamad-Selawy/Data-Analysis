# Power BI & DAX Fundamentals

Welcome to the **Power BI** learning repository! This directory contains comprehensive study guides and hands-on notebooks designed for beginner-to-intermediate data analysts looking to master Microsoft Power BI and Data Analysis Expressions (DAX).

---

## 📚 Notebooks Overview

### 1. [Power_BI.ipynb](./Power_BI.ipynb) — *Power BI Fundamentals: A Beginner Data Analyst Course*
A structured introduction to the Power BI ecosystem and core Business Intelligence concepts.

- **Core Topics Covered:**
  - **What is Power BI?** Business use cases, data storytelling, and the Power BI workflow.
  - **Power BI Ecosystem:** Desktop vs. Service vs. Mobile vs. Report Server.
  - **Desktop Views:** Navigating Report View, Data View, and Model View.
  - **Storage Modes:** Differences between Import, DirectQuery, and Dual modes.
  - **DAX Foundations:** Introduction to syntax, measures, and calculated columns.

---

### 2. [Essential_DAX_Functions_for_Power_BI.ipynb](./Essential_DAX_Functions_for_Power_BI.ipynb) — *Essential DAX Functions Study Guide*
A practical reference guide containing formulas, syntax explanations, and real-world examples across 8 key DAX categories.

- **DAX Categories Covered:**
  - 🔢 **Aggregation Functions:** `SUM`, `AVERAGE`, `COUNTROWS`, `DISTINCTCOUNT`, etc.
  - 🔄 **Iterating Functions (X-Functions):** Row-by-row context evaluation using `SUMX`, `AVERAGEX`, `COUNTX`.
  - 🔀 **Logical Functions:** Conditional logic using `IF`, `AND`, `OR`, `NOT`.
  - 📝 **Text Functions:** String manipulation using `CONCATENATE`, `MID`, `SEARCH`, `SUBSTITUTE`.
  - 📅 **Date & Time Functions:** Dynamic date creation using `CALENDAR`, `DATE`, `YEAR`, `MONTH`.
  - 🔍 **Filter Functions:** Context control using `CALCULATE`, `FILTER`, `ALL`, `ALLEXCEPT`, `RELATED`.
  - 📊 **Table Manipulation:** Dynamic table creation using `ADDCOLUMNS`, `SUMMARIZE`, `VALUES`.
  - ⏱️ **Time Intelligence:** Period-over-period metrics using `TOTALYTD`, `SAMEPERIODLASTYEAR`, `DATEADD`.
